# Contributing to AI Simulation Platform

Thank you for your interest in contributing to the **AI Simulation Platform**! We welcome contributions from the community.

## 🚀 Getting Started

### Prerequisites
- Node.js 16+ (for frontend)
- Python 3.9+ (for backend)
- Git

### Setup Development Environment

**Backend Setup:**
```bash
cd backend
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
pip install -r requirements.txt
```

**Frontend Setup:**
```bash
cd frontend
npm install
npm start
```

## 📝 Development Workflow

1. **Fork the repository** and clone your fork
2. **Create a feature branch** from `main`:
   ```bash
   git checkout -b feature/your-feature-name
   ```
3. **Make your changes** and commit with clear messages
4. **Push to your fork** and create a Pull Request
5. **Wait for review** and address feedback

## 🎯 Code Style Guidelines

### Python (Backend)
- Follow PEP 8 style guide
- Use type hints where possible
- Add docstrings to functions and classes

### TypeScript/React (Frontend)
- Use consistent formatting with Prettier
- Follow ESLint rules
- Add JSDoc comments for complex components

## 🧪 Testing

Please ensure all tests pass before submitting a PR:

```bash
# Backend
pytest

# Frontend
npm test
```

## 📋 PR Guidelines

- Keep PRs focused on a single feature or fix
- Write a clear description of your changes
- Reference related issues if applicable
- Include screenshots for UI changes

## 🐛 Bug Reports

Report bugs using GitHub Issues with:
- Clear title and description
- Steps to reproduce
- Expected vs. actual behavior
- System information (OS, versions)

## 💡 Feature Requests

Suggest features via GitHub Issues with:
- Clear use case and benefits
- Expected behavior
- Possible implementation approaches
