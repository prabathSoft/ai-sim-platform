# User Flow

## Step 1 — Select Algorithm
User chooses ML or CNN algorithm.

## Step 2 — Configure Model
User sets learning rate, epochs, batch size, activation.

## Step 3 — Data & Modeling
User generates or uploads dataset.

## Step 4 — Simulation
User starts training and sees real-time updates.

## Step 5 — Explain & Compare
User reviews metrics and visualizations.
