# 🚀 AI Simulation Platform — MVP Roadmap

This document outlines the MVP scope and future enhancements.

---

# 🎯 MVP Goals

### 1. Algorithm Selection
- List of classical ML + CNN options

### 2. Hyperparameter Configuration
- Learning rate
- Epochs
- Batch size
- Activation

### 3. Dataset Tools
- Synthetic dataset generator
- CSV upload
- Dataset preview canvas

### 4. Simulation Engine
- Fake training loop
- Metrics generation
- Decision boundary grid
- Feature maps (CNN)

### 5. Real-Time Updates
- WebSocket streaming
- Live canvas updates
- Metrics chart

- Export training report
